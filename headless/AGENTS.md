# Headless storefront

Read DESIGN_SYSTEM.md before changing storefront styling.

The user-approved palette is binding: Botanical Minimalism – Warm Sage & Cream.
Use app/styles/palette.css tokens across all locales, brands and page families.
Do not introduce independent literal UI colors or alternate brand palettes.
Gradients, transparency and tints must derive from these tokens. Preserve the
actual colors in product photography and logos and the existing Helvetica stack.
Maintain readable contrast, reduced-motion support and the gentle transitions.
Run the palette contract tests with the existing headless test command.
