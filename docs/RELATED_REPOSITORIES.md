# Related LEAFerservice repositories

This repository is the canonical LEAFerservice theme, integration and
documentation base. The following repositories remain separate source systems
and are linked here to avoid creating divergent copies:

- [davidnoehmke/leaferpage](https://github.com/davidnoehmke/leaferpage) —
  Hydrogen/headless storefront and its existing deployment examples.
- [davidnoehmke/LEAF-OS](https://github.com/davidnoehmke/LEAF-OS) — older
  Oxygen/headless experiments and storefront concepts.
- [LeafersShop/leafertheme_V1](https://github.com/LeafersShop/leafertheme_V1) —
  intended theme-only mirror. The canonical source currently lives under
  `theme/` in this repository.

Google Apps Script automation lives in `automation/google-apps-script/`.
Deployment examples live in `automation/ci-examples/` and are intentionally not
active GitHub Actions.
